# Task 4: Financial Fraud Detection Dashboard

## Objective

The objective of this project is to analyze financial transaction data and identify fraud patterns using Power BI. The dashboard provides insights into transaction behavior, fraud distribution, and transaction amounts.

## Dataset

Financial Fraud Detection Dataset

## Tools Used

* Power BI
* Microsoft Excel / CSV Dataset
* GitHub

## Dashboard Features

* KPI Cards for Transactions, Amount, Frauds, and Flagged Frauds
* Transaction Type Distribution
* Fraud Distribution Analysis
* Fraud by Transaction Type
* Transaction Amount by Type
* Account Balance Analysis
* Interactive Filters and Slicers

## Key Insights

* PAYMENT and CASH_OUT are the most common transaction types.
* Fraud is mainly associated with TRANSFER and CASH_OUT transactions.
* Fraud cases are rare but can have a significant financial impact.

## Files Included

* Financial Fraud Dashboard (.pbix)
* Dataset (.csv)
* Dashboard Screenshot (.png)
* README.md

## Conclusion

This dashboard helps visualize transaction patterns and identify fraudulent activities. It enables users to explore data interactively and gain actionable insights for fraud detection.
